## 4. 分问依赖关系

1. Q1 给出统一的功率—电量换算、供能平衡、储能状态转移和确定性费用最小化模型。
2. Q2 继承 Q1 的物理模型，增加滚动预测、紧急购电和跨日状态连续性。
3. Q3 继承 Q2 的负载预测与物理模型，以光伏多时次预报修正计划并加入偏差结算。
4. Q4 不另起炉灶，而是在 Q2/Q3 中替换或扩展电价信息模块，检验源—荷—价共同波动下的策略。

建议的统一论文主线为：**确定性日内优化 → 无前视年度滚动决策 → 多时次预报修正 → 波动电价下的源—荷—价协同调度**。

## 6. 明面任务之外的关键评分点

- **信息集合法性**：年度策略必须按发布时刻使用数据，不能以全年的实测值反向生成“当天 0:00 的计划”。
- **跨日储能价值**：Q2–Q4 未要求每日储电量回到原值，必须防止“每天末尾把电池放空”的有限时域偏差，同时保留跨日调度能力。
- **预测误差到决策误差的传播**：不仅比较光伏预测精度，还要比较误差是否改变购电、紧急购电和总费用。
- **多时次预报的信息价值**：Q3 的核心不是机械使用全部预报，而是比较 0/6/12/18 时策略的费用节省是否超过调整成本。
- **统一而可解释的结算口径**：计划、上调、下调违约和紧急购电必须分别记账，避免重复计费。
- **结果文件可复核**：144 个时段、全天汇总、六个 4 小时区间、储能首末状态和紧急购电连续区间必须互相对得上。
