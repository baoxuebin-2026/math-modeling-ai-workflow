# 模型路线

当前尚未确认具体赛题。本文件用于记录 AI 对每一问的候选模型、推荐模型、选择理由和风险判断。

## 决策原则

- 适配性优先于复杂度。
- 可解释性优先于微小精度提升。
- 每一问至少保留一个基线模型，便于对照。
- 只有当数据规模、非线性或任务结构确实需要时，才使用组合模型或黑箱模型。
