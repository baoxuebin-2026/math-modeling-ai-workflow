状态：`checked`。2026-09-10 用户确认采用无损标准化、实际锚点线性插值和独立输出目录；预处理脚本已执行并通过结构复核。

## 1. 处理原则

- `data/raw/附件/` 中原始工作簿只读，不覆盖、不改变数值。
- 实测负载、光伏和电价没有缺失、负值或重复日期，不删除、不插补、不缩尾。
- 极端峰谷符合业务量级，只在建模诊断中标记，不以统计规则替换真实值。
- 功率保留为 kW，同时按 $E=P/6$ 派生每10分钟电量 kWh。
- 所有决策时间采用区间末端时间戳；原表 `0:00+1` 解析为次日 00:00。

## 3. 时间与预报映射

附件1、2、4均严格展开为144个连续10分钟时段。附件3的“预报1小时”解释为发布时间后1小时的端点功率，依次至“预报24小时”。每次发布按如下方式映射：

1. 取发布时刻已经观测到的光伏实际功率作为 $h=0$ 锚点；
2. 与 $h=1,\ldots,24$ 的整点预测作分段线性连接；
3. 在 $h=1/6,2/6,\ldots,24$ 处求10分钟端点功率并截取非负值；
4. 再乘 $1/6$ 得到每格预测电量。

2025-01-01 0:00缺少上一日端点实测，仅此一个训练边界锚点取0 kW；正式填报从2月1日开始，因此不影响正式回测起点。全部整点插值回代误差为0 kW。为避免保存超过工作区单文件限制的冗余派生表，210240行的10分钟预报由求解器按发布记录即时生成，不持久化。

## 5. 对模型的影响

- 长表时间戳消除了跨日 `0:00+1` 与附件3未来24小时目标的错位风险。
- 同时保留 kW/kWh，便于预测仍在功率尺度上评价、优化统一在电量尺度上求解。
- 不平滑真实峰谷，保留紧急购电与储能功率约束真正需要应对的极端场景。
- 实际锚点插值只使用发布时刻已知信息，符合严格无前视口径。
- 按需插值减少冗余存储，但求解脚本必须调用同一公共函数，禁止各问重复实现不同插值逻辑。
