## 2. 分问解释

### Q1：储能具有明确的移峰套利价值

储能在低价时段及光伏富余时吸收能量，在高价时段放电。购电成本由48,052.05元降至35,126.95元，减少12,925.10元。调度过程中不存在同时充放电，SOC首末均为6000 kWh，逐格能量平衡和状态方程残差小于$10^{-12}$ kWh。

该结果证明在负载、光伏与价格完全已知时，储能能够有效重排购电时段；它是后续无前视模型的确定性价值上界和机制基准。

### Q2：日前预测总体有效，但局部低估会触发高价补购

1月滚动验证选择负载季节朴素预测和光伏HistGBR，归一化MAE分别约为3.03%和7.22%。全年计划成本为12,638,168.88元，紧急购电成本为1,065,614.09元，占总成本约7.78%。

指定日与年度热力图表明，风险不是均匀发生，而集中在少数月份和时段。模型应被解释为“在严格无前视条件下可执行的日前计划”，而不是完美预测或零紧急购电方案。

### Q3：信息更新的主要价值是风险压缩

Q3总成本比Q2减少110,834.49元。其计划与上调成本合计高于Q2日前计划成本，但紧急购电成本由1,065,614.09元降至372,631.41元，减少692,982.68元，最终形成0.81%的净成本改善。

因此Q3的核心贡献是把原本在应急市场发生的高价补购，提前转化为6、12、18时的计划上调。论文应突出紧急购电量下降78.69%，同时诚实说明总成本降幅仅0.81%。

### Q4：未知电价增加决策难度，但滚动更新仍有效

1月价格预测选择季节朴素方法，归一化MAE约4.53%。在未来价格未知条件下，Q4-3相对Q4-2多承担计划与调整费用，但紧急购电成本减少701,143.61元，最终总成本减少59,664.86元。

Q4-3与Q4-2的对比再次表明，滚动更新的稳健价值主要体现在削弱高价紧急购电暴露，而不是显著压低年度总费用。Q4与Q2/Q3使用的价格信息集不同，不应把二者成本差简单归因于某一个模型优劣。

## 3. 合理性与可信度

- Q1–Q4全部求解状态为HiGHS最优。
- 全年逐格能量平衡最大残差不超过$6.82\times10^{-13}$ kWh。

## 4. 论文主线

建议把四问组织为以下递进关系：

1. Q1给出完全信息下的储能调度价值和物理机制。
2. Q2引入日前预测误差，建立严格无前视基准。
3. Q3利用日内预报更新，将高价应急风险迁移为较早的计划修正。
4. Q4进一步撤去未来电价信息，验证滚动框架在源—荷—价共同不确定下仍能显著压缩紧急购电暴露。

核心创新表述应为“严格因果的信息更新与跨日储能状态协同”，而不是单纯强调复杂预测器或夸大费用下降。
