# 可视化生成与验收规则

## 1. 先确定证据角色

每张正文图必须绑定一个结论、一个数据源和一个论文位置。图用于趋势、机制、比较和稳健性；精确且简短的指定结果优先用表。探索图默认放 `tmp/`。

## 2. 正式导出

- 优先输出 SVG；同时输出 600 DPI PNG 作为兼容备份。
- 图内不放论文式标题，使用独立图注。
- 每张图最多 2 个子图，确需更多时先判断是否应拆图或放附录。
- 统一中文字体、负号、色板、线宽、单位和小数位。
- 文件使用稳定语义名，保存到 `figures/qX/`。

## 3. 最终尺寸验收

不能只查看原尺寸图片。必须按 Word、LaTeX 或 PDF 中的实际插入宽度预览并检查：

- 坐标、图例、注释和单位能否在正常阅读倍率下辨认；
- 是否有裁切、重叠、越界、模糊或颜色含义不清；
- SVG 字体在目标软件中是否正确显示；
- PNG 在目标尺寸下是否仍清晰；
- 图前是否说明观察目的，图后是否给出结论和边界。

未完成最终尺寸视觉检查的图片不得登记为 `paper_ready`。

## 4. 图表相邻排版

图与表不要机械堆在一起。两者相邻时，应在中间安排一小段约两行的解释文字，说明前一图的结论如何引出后一表的精确结果。

## 5. 登记字段

`registries/figure_evidence.csv` 至少记录：图号、claim id、源结果、源脚本、格式、正文位置、图注、图后结论、最终尺寸检查和验证状态。
