# 可视化规则

本文件用于约束所有分问可视化代码。

写可视化代码前，必须先完成 `docs/workflow/figure_planning_gate.md` 中的逐问图表证据链规划。本文只约束“怎么画”和“怎么验收”，不替代“该画什么图”的前置决策。

## 核心原则

1. 图表要服务论文结论，避免为画而画。
2. 每个 PNG 最多包含 2 个子图。
3. 不展示 100% 或 0% 这类无信息量图表。
4. 图内不写标题，标题和说明写在 `docs/figures/qx_figures.md`。
5. 配色优先使用 ColorBrewer、Tableau 或色盲友好色板。
6. 每张图必须有明确论文位置、变量、单位和关键发现。
7. 每张由 Python 生成的 PNG 必须由 AI 调用图片查看功能实际打开检查。只确认代码运行成功、文件存在或尺寸正常，不等于图片通过验收。
8. 若图片不达标，应优先修改可视化代码而不是在论文中解释缺陷。修改后必须重新运行、重新打开图片、重新验收。

## 默认论文图风格

本项目默认采用“低饱和、高留白、证据导向”的论文图风格。除非用户明确要求换风格，所有 `visualize_q*.py` 必须优先沿用 `code/common/plot_utils.py` 中的 `COLORS`、`setup_plot()`、`polish_axes()` 和 `savefig()`。

### 配色

- 主色：深蓝绿 `#264653`，用于主曲线、关键调度量和主要方案。
- 辅助色：柔橙 `#E9A03A`，用于上网、成本、负向或对照含义。
- 系统价值/推荐方案：低饱和绿 `#4F7F62`。
- 中性对照：灰色 `#7C8792`。
- 背景填充只使用浅色：`#DDEAF1`、`#F7E2C3`、`#E5EFE8`，透明度通常在 `0.55-0.90`。
- 网格线使用极浅灰 `#E6E8EB`，不可使用粗黑网格。
- 禁止默认 Matplotlib 彩虹色、过饱和红蓝、荧光色、大片纯色柱面和无意义渐变背景。

### 图型优先级

优先使用能表达机制和对比关系的图型：

- 时序功率：面积填充 + 少量关键曲线，不用密集柱状图。
- 正负量或双向交换：镜像面积线图或发散条带图，正负含义必须在图例或正文中说明。
- 方案成本曲线：点线图、垂线图、哑铃图、指数化对比图。
- 开停机调度：时段条带图或 Gantt 风格，不用粗糙 0-1 热力图。
- 24 场景分布：分位区间图、哑铃图、矩阵热力图，不默认使用箱线图。
- 参数扫描：共享横轴小多图、前沿图或敏感性曲线，不用拥挤双轴图。
- 场景矩阵：低饱和矩阵热力图，单元格之间用白色细线分隔，深色格必须切换白字。

柱状图只能用于少量离散指标对比，且必须说明为什么柱状图比哑铃图、点线图或区间图更合适。

### 版式

- 图内不放长标题；正文标题、图题和解释放到论文或 `docs/figures/`。
- 图例优先放在图上方或空白区域，不能遮挡数据。
- 注释只写短语，例如“75MWh：弃电清零”“0MWh：经济最优”，不能写整段结论。
- 坐标轴必须写清单位，如 `指标 / %`、`误差 / %`、`时间 / h` 或题目实际使用的单位。
- 文字、数值标签和图例不得贴边、重叠或压住关键曲线。
- 如果输出用于论文正文，单图宽高优先采用约 `6.7×3.3`、`6.8×3.8` 或 `7.2×4.0` 英寸；热力矩阵优先约 `5.2×3.9` 英寸。
- 颜色表达必须稳定：同一篇论文中，同类变量、基线方案、改进方案和风险状态应保持固定颜色语义。

### 禁用默认丑图

以下情况默认判为不合格，必须返工：

- 直接使用默认 Matplotlib 样式。
- 大量竖向柱状图堆在一起，且没有比点线、哑铃或区间图更强的表达理由。
- 默认箱线图、默认热力图、默认双轴图未经重构直接进入论文。
- 图内中文乱码、负号乱码、图例遮挡、标签贴边。
- 配色像临时调试图，和前文图风格不一致。
- 只展示结果数值，但看不出模型机制、调度规律或政策含义。

## 可视化代码输入

`visualize_q*.py` 的实现必须来自已经确认的图表证据链表。每张输出图都应能对应到：

- 一个论文结论。
- 一个图表类型。
- 一个数据来源。
- 一个正文或附录放置位置。
- 一个“不画什么”的取舍理由。

如果某张图无法对应上述信息，应删除该图或移入探索性分析，不进入论文主线。

## Python 出图闭环

每次运行 `code/q*/visualize_q*.py` 后，必须执行以下闭环：

```text
生成 PNG → 打开查看图片 → 记录问题 → 修改 visualize_q*.py → 重新生成 → 再次查看 → 手工更新 docs/figures/qx_figures.md
```

重点检查：

- 是否为空图、少数据图或筛选条件错误导致的假结论图。
- 文字、刻度、图例、注释是否重叠或越界。
- 坐标轴、单位、图例和颜色含义是否清楚。
- 是否仍是默认临时 matplotlib 风格。
- 是否符合本文件“默认论文图风格”。
- 图内是否塞入本该写进正文的长句结论。
- 缩小到论文栏宽后是否仍能读懂。

`visualize_q*.py` 只能生成图片，不能写入或覆盖 `docs/*.md`。图表说明文档必须由 AI 使用人工式 patch 更新，避免脚本批量覆盖已经打磨过的论文材料。

## 命名规范

```text
figures/q1/q1_fig01_data_distribution.png
figures/q1/q1_fig02_model_fit.png
figures/q1/q1_fig03_error_analysis.png
```

## 图表说明规范

每张图在 `docs/figures/qx_figures.md` 中至少记录：

- 图表文件路径
- 论文放置位置
- 图表类型
- 数据来源
- 变量与单位
- 关键发现
- 是否用于模型验证

## 常见题型推荐

| 题型 | 推荐图表 |
|---|---|
| 预测 | 实际值-预测值折线图、残差图、误差分布图 |
| 分类 | 混淆矩阵、ROC 曲线、特征重要性图 |
| 评价排序 | 权重柱状图、雷达图、排名稳定性图 |
| 优化 | 方案对比图、收敛曲线、约束满足情况图 |
| 聚类 | 降维散点图、轮廓系数图、群体画像图 |
| 机理仿真 | 参数曲线、情景对比图、敏感性分析图 |
