# 可视化规则

本文件沉淀自 `可视化计划.md`，用于约束所有分问可视化代码。

## 核心原则

1. 图表要服务论文结论，避免为画而画。
2. 每个 PNG 最多包含 2 个子图。
3. 不展示 100% 或 0% 这类无信息量图表。
4. 图内不写标题，标题和说明写在 `docs/figures/qx_figures.md`。
5. 配色优先使用 ColorBrewer、Tableau 或色盲友好色板。
6. 每张图必须有明确论文位置、变量、单位和关键发现。
7. 每张由 Python 生成的 PNG 必须由 AI 调用图片查看功能实际打开检查。只确认代码运行成功、文件存在或尺寸正常，不等于图片通过验收。
8. 若图片不达标，应优先修改可视化代码而不是在论文中解释缺陷。修改后必须重新运行、重新打开图片、重新验收。

## Python 出图闭环

每次运行 `code/q*/visualize_q*.py` 后，必须执行以下闭环：

```text
生成 PNG → 打开查看图片 → 记录问题 → 修改 visualize_q*.py → 重新生成 → 再次查看 → 写入 docs/figures/qx_figures.md
```

重点检查：

- 是否为空图、少数据图或筛选条件错误导致的假结论图。
- 文字、刻度、图例、注释是否重叠或越界。
- 坐标轴、单位、图例和颜色含义是否清楚。
- 是否仍是默认临时 matplotlib 风格。
- 图内是否塞入本该写进正文的长句结论。
- 缩小到论文栏宽后是否仍能读懂。

## 命名规范

```text
figures/q1/q1_fig01_data_distribution.png
figures/q1/q1_fig02_model_fit.png
figures/q1/q1_fig03_error_analysis.png
```

## 图表说明规范

每张图在 `docs/figures/qx_figures.md` 中至少记录：

- 图表文件路径
- 论文放置位置
- 图表类型
- 数据来源
- 变量与单位
- 关键发现
- 是否用于模型验证

## 常见题型推荐

| 题型 | 推荐图表 |
|---|---|
| 预测 | 实际值-预测值折线图、残差图、误差分布图 |
| 分类 | 混淆矩阵、ROC 曲线、特征重要性图 |
| 评价排序 | 权重柱状图、雷达图、排名稳定性图 |
| 优化 | 方案对比图、收敛曲线、约束满足情况图 |
| 聚类 | 降维散点图、轮廓系数图、群体画像图 |
| 机理仿真 | 参数曲线、情景对比图、敏感性分析图 |
