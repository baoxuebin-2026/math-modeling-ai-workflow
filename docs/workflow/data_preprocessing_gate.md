# 数据预处理门控

数据处理的目标是保护信息，不是机械清洗。

## 必查项目

检查缺失、异常、重复、类型、单位、时间/空间索引、编码、数据泄漏和附件结构性空白。原始文件保持只读，处理结果写入 `data/processed/`，来源与字段写入 `data/metadata/`。

## 风险分级

- 低风险：编码读取、日期解析、字段类型转换、单位派生、结构展开。记录后可直接执行。
- 中风险：插值、异常标记、重采样、标准化。说明影响和回滚方式；影响主结果时需确认。
- 高风险：删除样本、替换真实值、缩尾、平滑、外部数据拼接、可能使用未来信息。必须给出备选方案并由用户确认。

不再要求每一个低风险动作都机械提供 2—3 个方案。只有会改变样本、分布、信息集或结论的处理才进入硬确认。

## 结果记录

正式数据报告应记录输入版本、行列数、单位、处理数量、前后统计变化、信息时间边界和下游影响。无法证明不会改变结论的处理只能标记为诊断性。
