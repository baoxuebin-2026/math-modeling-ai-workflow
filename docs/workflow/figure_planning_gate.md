# 图表证据规划门控

绘图前先回答：图证明什么、数据来自哪里、放在论文哪里、为什么不能只用文字或表格表达。

每一问建立图表计划，至少包含：claim id、图表角色、源结果、推荐图型、正文位置、图注草稿、图后结论、风险边界和主文/附录决定。

正文图只保留以下角色：

- 解释模型或决策机制；
- 展示时间、空间、结构或分布规律；
- 比较基线与改进；
- 展示稳健性、风险或约束边界。

精确且简短的官方指定结果优先使用表。与表完全重复、只有单点或没有结论的图不进入正文。

图表计划确认后再编写 `code/qX/visualize_qX.py`。生成后按 `05_visualization_rules.md` 做最终尺寸视觉检查，并将证据写入 `registries/figure_evidence.csv`。
