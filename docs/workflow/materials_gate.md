# 论文素材包生成门控清单

本文件用于约束 `docs/paper_materials.md` 的生成。素材包是论文阶段的入口，不能把未确认的占位内容伪装成正式结论。

## 生成前条件

AI 生成 `docs/paper_materials.md` 前必须确认：

- 已按 `docs/workflow/national_prize_gate.md` 检查整篇论文主线、逐问递进、创新点和风险防守。
- `docs/01_task_alignment.md` 已由用户确认。
- `docs/02_model_plan.md` 已由用户确认。
- `docs/03_data_report.md` 已说明数据来源、处理动作和处理影响。
- `docs/04_result_summary.md` 已包含每问核心结果。
- `docs/05_visualization_plan.md` 已说明每张图服务哪个论文结论。
- `docs/06_validation_report.md` 已包含模型检验、敏感性分析或不适用理由。
- `docs/decision_log.md` 已记录关键决策。
- `docs/checkpoints.md` 已显示关键检查点均已确认或说明未完成原因。
- `docs/experiment_log.md` 已记录主要模型运行、图表生成和检验实验。
- `docs/active_solution_contract.md` 已更新当前确认方案。
- `docs/claim_evidence_map.md` 已建立论文结论与证据的对应关系。

如果上述文件中仍大量存在 `待确认`、`待补充` 或 `待用户决策`，AI 必须先提示缺口，不能把素材包称为最终论文素材。

## 素材包必须包含

- 题意与逐问任务。
- 每问模型路线和选择理由。
- 每问“基线模型 -> 改进模型 -> 检验/对比”的证据链，或明确说明不需要改进模型的原因。
- 整篇论文的统一主线、2-3 个核心创新点和对应证据。
- 每问在论文中的角色，以及前后问如何继承。
- 每问输入、输出、公式、算法和参数。
- 每问结果文件与图表说明。
- 模型检验、敏感性分析和局限性。
- 论文中建议使用的核心结论。
- 可以写入摘要的结论及其证据来源。
- 不能在论文中过度宣称的边界，例如非全局最优、样本限制、参数口径、外推范围等。
- 仍需用户确认的问题。

## 正文表格控制

论文正文表格数量和内容由题目、模型结果和用户决策共同确定。默认只保留能够支撑核心结论的表格，避免重复呈现同一组数据；容量扫描细表、对照实验和验证细节可放入附录或结果文档。表号、表名和是否进入正文必须在论文阶段明确记录，并经过用户确认。

## 获奖论文启发核对

生成素材包前，AI 应读取 `docs/workflow/award_paper_insights.md`，并检查：

- 各问是否形成递进关系。
- 是否有可解释基线。
- 是否有风险、情景、误差或鲁棒性处理。
- 是否有能写进论文的对比结果。
- 是否解释了结果差异，而不是只堆数值。
- `docs/claim_evidence_map.md` 中是否仍存在证据不足但准备写入摘要的结论。

## 进入论文阶段条件

只有当素材包满足以下条件，才进入 `paper/` 论文写作工作流：

- 每问主模型已确认。
- 每问核心结果已生成或明确说明无法生成的原因。
- 图表和结果能互相追溯。
- 摘要所需的核心数值已经存在。
- 用户确认可以开始论文阶段。
