# 论文素材与指定交付门控

## 进入写作前必须满足

- 每一问都在 `docs/deliverable_matrix.csv` 中有对应行。
- 官方指定的结果表、日期、区间、文件和精度均已提供，或有明确批准的省略记录。
- 主模型交接、正式运行、结果登记、数学验证和图表证据能够互相追溯。
- 摘要候选结论已经进入 `registries/claim_ledger.csv`，且引用的结果为 `paper_ready`。
- 官方页数、最终格式、匿名性、支撑材料和 AI 披露规则已经锁定。

## 表格优先级

1. 官方指定结果表：硬交付，不得为省页数改成纯文字。
2. 核心结果表：保留能回答分问或支撑摘要的精确值。
3. 参数、诊断和敏感性细表：合并、压缩或放附录。
4. 与图重复且没有新增精确信息的表：删除。

正文可选表数量只能约束第 2—4 类，不能覆盖第 1 类。宽表优先改成一个总表下的 `(a)(b)(c)` 子表或纵向紧凑表。

## 写作阻塞条件

存在以下任一情况时不得进入正式分章写作：指定交付缺失、结果真源不明、旧缓存与正式工作簿不一致、开放 P0/P1 数学问题、图表未做最终尺寸检查、官方页数范围未知。
