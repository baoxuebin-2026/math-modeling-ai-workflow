# 高质量竞赛论文总门控

目标是形成题目贴合、数学合理、证据可信、表达清楚、可复现且边界明确的论文，不承诺奖项。

## 统一论证链

```text
题目与官方交付 → 关键困难 → 基线模型 → 必要改进 → 正式求解 → 结果解释 → 验证防守 → 论文结论
```

任何模型、参数、图表或实验，如果不能说明支撑哪项题目要求或论文结论，默认不进入主线。

## 建模门槛

- 各问形成继承关系，而不是模型拼盘。
- 变量、单位、目标、约束和边界能够追溯到题面、数据或明确假设。
- 创新解决真实痛点，并有基线或消融证据。
- 复杂模型增加的收益足以覆盖实现、验证和表达成本。
- 重要模型在逐式解释后提供“目标函数 + 分组约束”的紧凑总括。

## 结果门槛

- 官方指定表和文件完整提供。
- 结果来自正式运行和唯一登记，不来自旧缓存或截图。
- 报告核心数值、变化原因、基线差异、异常机制和风险边界。
- “最优、显著、鲁棒、稳定”等强词具有对应证据。

## 写作门槛

- 摘要只使用已验证结果；问题分析提前说明统一主线和创新动机。
- 每章标题服务真实内容，三级标题通常不超过 4 个，确有必要可到 5 个。
- 假设简洁，符号表只保留核心符号、含义和单位。
- 官方页数先于写作锁定；逐章控制预算，单轮压缩通常不超过 20%—30%。
- 图表靠近解释位置，均有图题/表题和正文引用。

## 最终防守

按模型类型完成直接检查、情景检查或鲁棒性验证；再由 `math-consistency`、`math-review` 和 `math-compliance` 对最终导出文件执行数值、格式、页数、匿名性、引用和提交包核验。存在开放 P0/P1 问题时不得标记最终就绪。
