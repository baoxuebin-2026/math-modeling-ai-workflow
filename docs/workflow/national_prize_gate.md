# 国家一等奖导向总门控

本文件用于把整个工作流提升到“以最终论文为准”的国奖级标准。目标不是堆复杂模型，而是形成逻辑完整、创新适度、证据充分、表达清晰、可复现可防守的数学建模论文。

## 总原则

从读题开始，所有建模、代码、图表和检验都必须服务最终论文的论证链：

```text
题目理解 → 关键难点 → 统一主线 → 基线模型 → 创新改进 → 求解实现 → 结果解释 → 对比检验 → 稳健性防守 → 论文表达
```

任何模型、参数、图表或实验，如果不能回答“它在论文中支撑什么结论”，默认不进入主线。

## 国奖级论文应具备的特征

| 维度 | 要求 |
|---|---|
| 主线统一 | 各问不是散装求解，而是围绕同一核心思想递进 |
| 问题拆解 | 能指出题目真正难点、隐含目标和前后问依赖关系 |
| 模型层次 | 至少有可解释基线和适度改进；复杂模型必须有必要性 |
| 创新合理 | 创新来自题目痛点，例如误差、风险、约束、非线性、多目标、鲁棒性、可解释性 |
| 结果可信 | 有基线对比、约束验证、敏感性分析或鲁棒性检验 |
| 图表有力 | 核心图构成证据链，而不是装饰 |
| 语言克制 | 不夸大最优性、显著性和适用范围；边界条件写清楚 |
| 可复现 | 数据、代码、参数、结果和论文结论可以互相追溯 |

## 读题阶段必须输出

在 `docs/00_problem_extracted.md` 和 `docs/01_task_alignment.md` 中，必须形成以下内容：

- 题目明面任务与隐含评分点。
- 每问在整篇论文中的角色：基础、扩展、检验、优化、推广或应用。
- 各问之间的继承关系：后一问复用前一问的哪些变量、结果、约束或思想。
- 可能冲击高奖的关键难点：误差来源、约束复杂性、数据稀疏性、动态变化、优化规模、评价口径等。
- 不能碰的风险：题意误读、过度清洗、过度平滑、未验证最优、图表空泛、结论夸大等。

## 建模阶段必须输出

在 `docs/02_model_plan.md` 中，每问必须给出“基线-改进-防守”结构：

| 项目 | 要求 |
|---|---|
| 基线模型 | 稳、可解释、贴题，作为最低可提交方案 |
| 改进模型 | 针对真实痛点，而不是为了显得高级 |
| 创新点 | 说明创新发生在哪一层：数据、变量、目标函数、约束、求解、检验或表达 |
| 对照方式 | 说明如何证明改进有效，例如指标提升、约束更稳、鲁棒性更好 |
| 风险边界 | 说明该模型不保证什么，适用条件是什么 |

创新优先级建议：

1. **统一框架创新**：把多个问题放进同一建模主线，例如校准-融合-预测-优化。
2. **约束表达创新**：把题目条件转成清晰、可解释、可检验的数学约束。
3. **鲁棒性创新**：加入误差、风险、敏感性或边界情景。
4. **求解策略创新**：基线解、改进解、精确对照或局部搜索配合，说明最优性边界。
5. **图表表达创新**：用证据链图表解释机制，而不是只展示结果。

不推荐的“伪创新”：

- 只换一个复杂算法名，但结果和解释没有提升。
- 为了机器学习而机器学习，样本量或特征不支持。
- 加入无法验证的外部假设。
- 把早期尝试过但最终未采用的模型写成主模型。

## 结果阶段必须输出

在 `docs/04_result_summary.md` 中，每问结果不能只报数，必须回答：

- 核心数值是什么。
- 这些数值说明了什么。
- 相比基线或上一问有什么变化。
- 变化是否符合直觉，若不符合，原因是什么。
- 哪些结果可以写入摘要，哪些只能作为过程结果。
- 是否存在贴边约束、敏感参数、异常点或口径风险。

## 图表阶段必须输出

图表必须服务论文证据链。进入可视化代码前，必须按 `docs/workflow/figure_planning_gate.md` 完成逐问图表规划，并明确：

- 哪些图是国奖级核心图，必须精修。
- 哪些图只适合附录。
- 哪些图不画，因为无法支撑主结论。
- 每张正文图在论文中对应哪一句结论。

## 检验阶段必须输出

在 `docs/06_validation_report.md` 中，至少应覆盖以下一种或多种国奖级防守：

- 主模型与基线模型对比。
- 参数敏感性或扰动分析。
- 约束满足与边界裕度检查。
- 极端情景或风险情景测试。
- 结果稳定性或显著性分析。
- 优化模型的最优性边界或候选集内对照。

若某项不适用，必须说明“不适用”的数学或题意原因。

## 论文写作阶段必须检查

进入 `paper/` 写作前，AI 必须先形成“论文主线摘要”，包括：

- 本文统一主线是什么。
- 各问如何递进。
- 核心创新点是哪 2-3 个。
- 核心结果是哪 3-5 个。
- 最需要防守的风险是什么。
- 哪些图表构成核心证据链。

每一问模型章节建议采用：

```text
问题难点 → 数据/题意观察 → 基线模型 → 改进模型 → 求解与参数 → 结果 → 对比/验证 → 本问小结
```

如果某问不适合写基线和改进，也必须解释原因，并用“模型选择理由 + 检验”补足说服力。

## 国奖级最终检查清单

定稿前至少检查：

- 摘要是否体现统一主线、核心方法、关键结果和验证结论。
- 问题分析是否提前埋下后文模型主线。
- 符号说明是否覆盖核心变量，且不堆无用符号。
- 每问小标题是否具体，避免机械套话。
- 每个公式前后是否有题意解释。
- 每个核心结果是否有图、表或检验证据。
- 创新点是否真实服务题目，而不是空喊高级。
- 局限性是否具体但不自毁主结论。
- 所有“最优、显著、鲁棒、稳定”等强词是否有证据支撑。
