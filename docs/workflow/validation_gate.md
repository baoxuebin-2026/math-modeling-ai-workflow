# 模型验证门控

验证负担必须与模型风险匹配，不机械要求每问都做同一种灵敏度分析。

## 验证等级

| 等级 | 适用情况 | 最低证据 |
|---|---|---|
| `direct-check` | 确定性公式、线性规划、直接计算 | 量纲、守恒、边界、约束残差、费用恒等式 |
| `scenario-check` | 多情景、政策、风险或替代方案 | 完整情景对比和明确通过标准 |
| `robustness-required` | 结论依赖权重、阈值、拟合参数、随机搜索或容差 | 参数范围、稳定指标、通过标准和降级规则 |
| `diagnostic-only` | 探索性检查或证据不完整 | 只用于发现问题，不进入摘要和结论 |

## 通用检查

- 模型与题设约束一致；
- 单位、时间步长、索引终点和状态更新闭合；
- 正式运行状态、容差、随机种子和警告有记录；
- 基线与改进采用相同分母、场景和评价指标；
- 特殊零值、突变、贴边解和反直觉结果有机制解释；
- 失败的验证会使对应结果降级，而不是被文字掩盖。

只有在结果登记、数值诊断和一致性审查均通过后，结论才能标记为 `paper_ready`。
