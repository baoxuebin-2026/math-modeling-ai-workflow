# 模型检验门控清单

本文件用于约束模型检验阶段。AI 不能只检查文件是否存在，必须判断每个模型是否需要检验、需要什么检验、检验结果是否通过，以及未通过时如何改进。

## 1. 检验必要性判断

对每个模型先判断：

| 模型类型 | 常见检验 |
|---|---|
| 回归模型 | 残差分析、R²、RMSE、显著性检验、多重共线性 |
| 预测模型 | 回测、MAE、RMSE、MAPE、置信区间 |
| 分类模型 | 准确率、F1、AUC、混淆矩阵、阈值敏感性 |
| 聚类模型 | 轮廓系数、稳定性、群体可解释性 |
| 评价排序模型 | 权重敏感性、排名稳定性、一致性检验 |
| 优化模型 | 约束满足度、目标值对比、复杂度、敏感性 |
| 机理模型 | 边界条件、参数敏感性、量纲一致性、实际合理性 |
| 仿真模型 | 多场景测试、极端情景、随机重复实验 |
| 机器学习模型 | 交叉验证、泛化能力、过拟合检查、特征重要性 |

如果某个模型不需要统计检验，也必须说明理由，例如纯确定性规划模型没有随机误差项，但仍需要约束满足和敏感性分析。

## 2. 检验方法选择

每个检验应记录：

| 项目 | 要求 |
|---|---|
| 检验对象 | 哪个模型或哪一问 |
| 检验类型 | 拟合、误差、稳定性、合理性、泛化、鲁棒性等 |
| 具体方法 | RMSE、残差图、交叉验证、权重扰动等 |
| 选择理由 | 为什么适合当前模型 |
| 通过标准 | 数值阈值或逻辑标准 |
| 结果解释 | 通过/未通过/需改进 |

## 3. 必做检验

除非题目完全不适用，建议至少覆盖：

- 主模型有效性检验。
- 基线模型对照。
- 2-3 个核心参数的敏感性分析。
- 极端或边界情景测试。
- 结果与题意约束的一致性检查。

## 4. 结果输出

检验结果应写入：

- `docs/06_validation_report.md`
- 必要时输出图表到 `figures/validation/`

报告至少包含：

- 检验清单。
- 核心公式或指标定义。
- 关键数值。
- 统计或场景解释。
- 通过/未通过判定。
- 未通过原因。
- 改进建议。

## 5. 图表要求

常见检验图：

- 残差分布图。
- Q-Q 图。
- 实际值 vs 预测值图。
- 误差箱线图。
- 灵敏度折线图。
- 权重扰动下排名变化图。
- 优化算法收敛曲线。
- 约束违背情况图。

图表必须说明服务哪个检验结论，不能只为装饰。

## 6. 论文落地

论文中的模型检验部分应突出：

- 为什么需要这些检验。
- 检验结果说明模型是否可靠。
- 哪些条件下模型不稳定。
- 如何改进。
- 检验结论如何支撑最终建议。
