# 参考论文格式提炼

本文件根据已上传的两篇历史论文提炼格式参考。历史论文内容质量不作为范本，只参考结构和排版习惯。

## 可参考之处

- 标题置于摘要前，标题应突出核心模型和研究对象。
- 摘要按问题分段，便于评委快速定位每问方法和结果。
- 关键词紧跟摘要。
- 本工作流采用顺序：问题重述、问题分析、模型假设、符号说明、模型建立与求解、模型检验、模型优缺点与改进、参考文献、附录。
- 图表在正文中需要编号和解释。
- 附录可以列出核心代码文件和补充图表。

## 不建议照搬之处

- 背景过长且泛泛。
- 摘要存在过多主观评价，量化支撑不足。
- 代码片段可能不完整或不可运行。
- 图表数量较多但部分说明重复。
- 公式和符号存在不一致风险。

## 对本工作流的启发

- 论文写作阶段应保留“按问题分段”的清晰结构。
- 每问需要形成“模型-代码-图表-结果-验证”的闭环。
- 模型检验作为第六章独立汇总；模型优缺点、改进与推广作为第七章。
- 摘要最终版必须在结果确认后再写。
- 附录代码只列核心文件，不贴大量不可读代码。
