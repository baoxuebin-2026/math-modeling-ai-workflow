# 五、模型建立与求解

## 5.1 问题一模型的建立与求解

问题一给定单日144个10 min时段的电价、负载和光伏预测，需要在0时一次性确定全天计划购电与储能充放电策略。本问不存在预测误差和日内计划修正，核心是利用储能在低价或光伏富余时吸收电量，在高价时段释放电量，并在满足逐格供能平衡、设备运行边界和首末储电量一致的条件下，使全天购电费用最小。该模型同时作为问题二至问题四的物理与费用基线。

### 5.1.1 无储能基线

先构造无储能直接购电方案，用于检验数据量级并量化储能价值。第 $t$ 格负载和光伏功率分别为 $L_t$、$P_t$，换算后的电量为

[
\ell_t=L_t\Delta t,qquad p_t=P_t\Delta t,
qquad \Delta t=\frac{1}{6}\ \mathrm h.
]

无储能时，光伏优先供给小区负载，不足部分由外网购买，富余部分形成弃光。因此基线购电量与弃光量分别为

[
G_t^{mathrm{base}}=\max(\ell_t-p_t,0),
]

[
W_t^{mathrm{base}}=\max(p_t-\ell_t,0),
]

基线购电费用为

[
J_{mathrm{base}}=\sum_{t=1}^{144}\pi_tG_t^{mathrm{base}}.
]

将附件1数据代入可得，无储能时全天购电量为 $61789.9354\ \mathrm{kWh}$，弃光量为 $6247.9630\ \mathrm{kWh}$，购电费用为 $48052.05$ 元。该方案不包含跨时段能量转移，因而不能利用低价电能或白天富余光伏替代高价时段购电。

### 5.1.2 确定性日内线性规划模型

问题一的决策变量包括计划购电量 $G_t^0$、储能充电量 $C_t$、储能向母线放电量 $D_t$、时段起点储电量 $S_t$、实际利用光伏量 $R_t$、弃光量 $W_t^{pv}$ 和已付费但未使用的计划电量 $W_t^g$。由于计划制定时全天数据均已知，且外网购电能力未设置上限，本问无需设置紧急购电变量。

每个时段的母线能量平衡为

[
G_t^0+D_t+R_t=\ell_t+C_t+W_t^g,
qquad t=1,2,\ldots,144.
]

光伏电量在实际利用和弃光之间分配，即

[
R_t+W_t^{pv}=p_t.
]

储能状态转移方程为

[
S_{t+1}=S_t+\eta_cC_t-\frac{D_t}{\eta_d},
]

其中 $C_t$ 按母线侧输入计量，$D_t$ 按母线侧输出计量，且 $\eta_c=\eta_d=0.9$。由额定充放电功率 $5000\ \mathrm{kW}$ 可得单格最大充、放电量为

[
P^{max}\Delta t=5000\times\frac{1}{6}
=833.3333\ \mathrm{kWh}.
]

相应运行边界为

[
1200\leq S_t\leq10800,
]

[
0\leq C_t,D_t\leq833.3333,
]

[
G_t^0,R_t,W_t^{pv},W_t^g\geq0.
]

按照题目要求，初始与末端储电量均取 $6000\ \mathrm{kWh}$：

[
S_1=S_{145}=6000.
]

以全天计划购电费用最小为目标，问题一可归结为如下确定性连续线性规划：

[
\min J_1=\sum_{t=1}^{144}\pi_tG_t^0
]

[
\text{s.t.}quad
\begin{cases}
G_t^0+D_t+R_t=\ell_t+C_t+W_t^g,\\
R_t+W_t^{pv}=p_t,\\
S_{t+1}=S_t+\eta_cC_t-D_t/\eta_d,\\
1200\leq S_t\leq10800,\\
0\leq C_t,D_t\leq833.3333,\\
G_t^0,R_t,W_t^{pv},W_t^g\geq0,\\
S_1=S_{145}=6000.
\end{cases}
]

目标函数、约束和变量均为线性连续形式，因此不需要引入整数变量或启发式算法。

### 5.1.3 词典序去退化与求解方法

只最小化购电费用时，在线性规划的等价最优解中可能出现同时充放电或无意义弃用。为获得物理上更清晰的调度轨迹，本文采用两阶段词典序求解。第一阶段求得最优购电费用 $J_1^*$；第二阶段保持

[
J_1\leq J_1^*+\varepsilon,qquad
\varepsilon=10^{-7}\max(1,|J_1^*|),
]

再最小化辅助目标

[
\Phi=\sum_{t=1}^{144}
\left[0.6(C_t+D_t)+1.1(W_t^{pv}+W_t^g)\right].
]

其中，较大的弃用系数用于优先消除无意义弃光和未使用购电量，充放电项用于压缩不必要的能量循环；该辅助目标只在费用等价的解中进行选择，不改变第一阶段的最优购电费用。模型使用 HiGHS 线性规划求解器计算，并在输出后独立复算逐格能量平衡、储能状态方程、SOC边界和首末状态。

### 5.1.5 可行性检验与结果分析

求解器返回最优状态。逐格独立复算得到最大能量平衡残差为 $1.14\times10^{-13}\ \mathrm{kWh}$，最大储能状态残差为 $8.60\times10^{-13}\ \mathrm{kWh}$；SOC最小值和最大值分别为 $1200$ 与 $10800\ \mathrm{kWh}$，同时充放电时段数为0，说明所得策略满足全部物理约束。

为检验效率口径对结论的影响，将充、放电效率同时改为0.85和0.95后，购电费用分别为 $36603.41$ 元和 $33767.03$ 元，相对无储能基线仍分别节省 $23.83\%$ 和 $29.73\%$。费用随效率提高而下降，符合储能损耗机理，且“储能能够显著降低确定性单日购电费用”的结论未发生反转。

综上，问题一的最优调度通过“低价或光伏富余时充电—高价时放电”同时实现了光伏消纳与购电时段重排，在首末储电量相等的条件下将全天购电费用降低 $26.90\%$。本问建立的能量平衡、储能状态和费用核算口径将在后续问题中继续沿用；问题二将在此基础上撤去未来实际源荷信息，进一步处理预测误差、紧急购电和跨日SOC连续性。
