# 科研论文图片生成与验收门控

本文件用于约束论文阶段的所有图片生成、修改、引用和验收。核心原则是：图片不是“有文件即可”，而必须达到可直接放入数学建模论文的科研图质量。

## 强制流程

每生成或修改一张图片，必须执行以下步骤：

1. 生成图片文件，并确认数据来源真实可追溯。
2. 立即调用查看图片功能打开该图片，不得只检查文件是否存在。
3. 按本文“逐图验收清单”检查。
4. 若任一项不通过，修改代码或图片后重新生成，并再次查看。
5. 将验收结果写入对应章节 review 或 `paper/reviews/figure_quality_review.md`。

禁止行为：

- 禁止批量生成图片后不查看就写入正文。
- 禁止把空图、假数据图、遮挡图、文字重叠图放入正文。
- 禁止用默认临时 matplotlib 风格直接交付核心图。
- 禁止在图内塞入大段结论性文字；结论应写在正文。

## 逐图验收清单

每张图必须检查：

| 检查项 | 通过标准 |
|---|---|
| 数据真实性 | 图中数据来自 `data/processed/`、`docs/results/` 或明确结果文件，不为空、不缺列、不与表格冲突 |
| 图像可读性 | 标题、轴标签、图例、刻度、注释不重叠、不越界、不遮挡主体 |
| 科研图风格 | 字体、线宽、颜色、留白统一；不使用粗糙默认样式；不过度装饰 |
| 信息密度 | 一张图只回答一个核心问题；必要信息足够，冗余说明不进图 |
| 论文适配 | 黑白打印或缩小后仍可辨认；图题能独立说明内容 |
| 结论支撑 | 正文引用该图时，必须说明它支撑哪个结论 |
| 文件一致性 | 文件名、图号、正文图题、实际内容一致 |

## 核心图高标准

以下类型通常属于核心论文图，必须优先精修，不得用临时版本：

- 总体建模流程图。
- 参数搜索或目标函数曲线图。
- 模型前后对比图。
- 残差、误差或分布诊断图。
- 置信区间、显著性或不确定性分析图。
- 敏感性、鲁棒性或参数扫描图。
- 调度、路径、网络、分类或决策结果图。
- 约束裕度、风险边界或可行性验证图。

核心图额外要求：

- 不允许图中出现大段解释性句子。
- 不允许标题、图例、标签遮挡图像主体。
- 不允许坐标轴无单位。
- 不允许空数据或只有一个无意义点的图。
- 不允许图中结论和正文结论不一致。

## 常见问题与处理

| 问题 | 处理方式 |
|---|---|
| 文字重叠 | 增大画布、减少图内文字、调整图例位置或把解释移入正文 |
| 图内说明太多 | 只保留标签和必要数值，结论性描述写到正文 |
| 空数据图 | 回查数据文件和筛选条件；不能用空图占位 |
| 默认风格明显 | 统一字体、字号、线宽、配色、网格和边距 |
| 调度/时间线图拥挤 | 分泳道、错层、缩短标签、扩大横向画布 |
| 敏感性/参数扫描图重叠 | 使用分组柱状图或上下组合图，避免双轴遮挡 |
| 置信区间图单薄 | 加零参考线、误差棒、数值标签和适当留白 |

## 验收记录模板

建议写入：

```text
paper/reviews/figure_quality_review.md
```

记录格式：

```markdown
# 图片质量验收记录

| 图号 | 文件 | 是否查看 | 数据是否非空 | 是否无重叠 | 是否可读 | 是否采用 | 修改记录 |
|---|---|---|---|---|---|---|---|
| 图1 | `figures/...png` | 是 | 是 | 是 | 是 | 正文 | 调整图例位置 |
```

## 最终判定

只有当图片通过查看和逐项验收后，才能在正文中引用。若图片只适合辅助说明但达不到正文质量，应放入附录或不使用。
